# 字成图

输入一个汉字，选择简体／繁体和圆框／方框，下载透明背景的 PNG 或 SVG 图标。

## 启动

需要 Node.js 18 或以上版本。在本目录运行：

```sh
npm start
```

打开终端输出的地址，默认是 http://127.0.0.1:4173。端口被占用时会自动使用下一个端口。也可以用 `HANZI_ICON_PORT` 指定起始端口。

无需安装 npm 依赖，无需构建。使用本地 HTTP 服务访问，不能直接双击 HTML 文件，否则浏览器会限制读取字体文件。

## 功能与规则

- 输入完成后，只保留首个字符并转换成一个汉字。兼容中文输入法，组词过程中不截断，选字完成后再处理。
- 数字、英文字母、常见符号自动映射为汉字，也支持对应的全角数字／字母／ASCII 标点。
- 空输入、不支持的字符或字体缺字时禁止导出。Emoji、带重音字母、其他语言文字、未收录的符号会提示输入不合法。
- 简体／繁体转换；繁体采用台湾常用字形。单字转换采用词库的默认对应，有歧义时请直接输入目标繁体字，例如「發」或「髮」。
- 圆形／方形细边框，固定深色，自动按字形轮廓居中。
- 512 × 512 PNG，透明背景。
- 点击「下载 SVG」弹出尺寸菜单，可选择 32、64、128、256、512 像素；文件的宽高采用所选尺寸，`viewBox` 保持一致，字形和边框按比例缩放。
- 「全部下载」生成一个 ZIP，内含上述 5 个尺寸的 SVG，避免浏览器拦截连续多文件下载。
- SVG 使用字形路径，没有外链字体或 `<text>` 元素；外框与汉字都是矢量。
- 32、48、64 像素的小尺寸预览。
- 透明底纹／纸面预览切换，只改变预览底色，导出文件始终透明。
- 一键复制 SVG 源码；剪贴板不可用或未获授权时会提示使用下载。
- 默认以「汉」预览；随机换字提供不重复当前字的灵感。
- 桌面使用左右制字台，手机将输入与选项并排排列，缩短到预览的滚动距离。
- 支持键盘焦点、SVG 菜单方向键／Home／End／Escape 导航，以及系统减少动态效果设置。

### 视觉与交互

采用暖纸底色、朱砂印记与宋体标题，输入框借用字帖辅助线，预览保留版心角标。页面中的辅助线、底纹和装饰不进入导出文件。简繁转换反馈预留两行高度，歧义说明集中放在「关于这枚图标」，切换时下方控件位置保持稳定。首次读取字体显示加载状态，字体就绪后切字与换框直接更新，避免重复显示加载占位。

生成、复制、下载和失败状态各有反馈；空输入、不支持字符、缺字及加载失败时禁止导出，避免下载旧图标。没有增加账号、网络服务或外部运行时依赖。

### 输入示例

先去掉首尾空白，再取首个完整字符进行映射；不会跳过不合法的首字符去寻找后面的汉字。输入框会回填转换后的一个汉字，之后按当前简体／繁体选项生成图标。

| 输入 | 回填汉字 | 说明 |
| --- | --- | --- |
| 汉字图标 | 汉 | 多字保留首字 |
| 0～9 | 零、一、二、三、四、五、六、七、八、九 | 单个数字对应的汉字 |
| 123 | 一 | 多位数字也只处理首位 |
| a / A / Ａ | 啊 | 大小写与全角等效 |
| , / ， | 逗 | 逗号 |
| . / 。 | 句 | 句号 |
| ? / ？ | 问 | 问号 |
| ! / ！ | 叹 | 感叹号 |
| 😊 / 1️⃣ / é / あ | 不合法 | 不将组合字符拆成其中的数字或字母 |

26 个英文字母采用固定对应表：

| 字母 | 汉字 | 字母 | 汉字 |
| --- | --- | --- | --- |
| A | 啊 | N | 南 |
| B | 波 | O | 哦 |
| C | 春 | P | 平 |
| D | 东 | Q | 清 |
| E | 鹅 | R | 日 |
| F | 风 | S | 山 |
| G | 光 | T | 天 |
| H | 花 | U | 优 |
| I | 爱 | V | 维 |
| J | 江 | W | 文 |
| K | 空 | X | 星 |
| L | 林 | Y | 月 |
| M | 木 | Z | 竹 |

I、U、V 没有常规以它们开头的汉语拼音，因此例外地按英文字母读音近似对应「爱、优、维」。其余字母按汉语拼音首字母选择。完整符号表在 `public/app.js` 的 `symbolGroups` 中，未收录的符号不做猜测。

页面不调用 AI 服务，输入和导出全部在浏览器中完成。字体、转换词库和脚本已放在项目内，运行时不依赖外部 CDN。字体没有覆盖所有 Unicode 汉字，缺字时页面会提示。

## 文件

- `public/index.html`：页面结构。
- `public/styles.css`：桌面和窄屏样式。
- `public/app.js`：简繁转换、字体加载、SVG 绘制和 PNG 导出。
- `public/assets/fonts/`：思源黑体 Medium，简体和繁体 OTF。
- `public/assets/vendor/`：本地 JavaScript 库及许可文件。
- `public/assets/sources.json`：下载来源、字体修订版本和文件摘要。
- `server.mjs`：只提供 `public/` 文件的本地静态服务。

## 来源与许可

- [Adobe 思源黑体](https://github.com/adobe-fonts/source-han-sans)：SIL Open Font License 1.1，许可保留在 `public/assets/fonts/LICENSE.txt`。
- [opentype.js 1.3.4](https://github.com/opentypejs/opentype.js)：MIT，读取 OTF 并提取字形路径。
- [opencc-js 1.4.2](https://github.com/nk2028/opencc-js)：MIT，使用其完整浏览器构建进行简繁转换；上游词库许可一并保留在 `public/assets/vendor/`。
- [fflate 0.8.2](https://github.com/101arrowz/fflate)：MIT，在浏览器内打包全部尺寸的 SVG，许可保留在 `public/assets/vendor/fflate-LICENSE.txt`。

## 本轮验证（2026-10-27）

- 实际浏览器检查桌面、820 px 平板、390 px 手机和 320 px 窄屏布局。
- 验证多字截断、全角字母映射、空输入、Emoji 拒绝、简繁转换、方圆切换、预览底色和 SVG 复制。
- 在 1280、390、320 px 视口反复切换「汉／漢」，实测外框选项、预览、小尺寸区、导出区和关于区的位置与高度均保持一致。
- 验证 SVG 菜单 End / Escape 操作；实际下载 PNG、32 px SVG 和全部尺寸 ZIP。
- 检查 PNG 为 512 × 512，存在透明像素；SVG 为字形路径且无外链字体；ZIP 含 32、64、128、256、512 五种尺寸，viewBox 一致。
- `node --check public/app.js`、`node --check server.mjs` 和 `git diff --check` 通过。

检查使用 Codex 内置浏览器的响应式视口，不等同于真实手机和跨浏览器验收。真实中文输入法组词、慢网／断网字体加载及系统减少动态效果尚未专项实测。本项目没有预设的自动化测试或构建步骤。
